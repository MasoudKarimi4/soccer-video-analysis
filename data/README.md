# Input data

Put local footage here, for example `soccer_footage.mp4`, or pass another path to `--video`. Video files are excluded from Git.

The supplied experiment uses the first 10 seconds (300 frames at 30 FPS) of the original project video. The paper describes YouTube-sourced broadcast footage; no verified download URL was supplied. [Verified asset metadata](../results/verified/assets.json) records the local source fingerprint.

Use footage you can access appropriately. For a different match, omit the example seed and recalibrate the red/light jersey masks if needed. The checked-in manual seed belongs only to the original clip.
